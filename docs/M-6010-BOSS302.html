BOSS 302 ENGINE BLOCK

M-6010-BOSS302
MSRP $2,250.00
WARNING: This part is designed and intended for competition use only or off-highway use only. It should not be installed on a vehicle that is driven on public roads and highways.

Overview

Unleash legendary power with the BOSS 302 Engine Block, expertly crafted by Ford Performance Engineers for unmatched strength and versatility. Built from diesel-grade iron, it's your ultimate choice for dominating both track and street.

Features & Specifications

  • Ford Performance Engineers have designed the replacement for the legendary BOSS 302 and 351 blocks using the latest technology and manufacturing techniques from both the production and racing worlds.
  • 4.125" bore capacity, finished at 3.990" to 3.995" rough bore
  • 8.2" deck height, finished at 8.200" plus .010" to .015"
  • Designed with optimized cylinder wall length for stroker applications up to 3.5" with no grinding or clearancing
  • Splayed 4-bolt main on 2, 3, 4 main caps
  • 2-bolt main on first and fifth main caps
  • Main bearing bores finished to low limit
  • Finished lifter bores
  • Machined to accept factory roller lifter guides and lifter guide retainer
  • NASCAR inspired front oil feed on both lifter galleys
  • Revised cooling system passageways
  • Siamese bore with drilled coolant crossover holes
  • Increased bulkhead material
  • Threaded core and galley plugs (straight thread port plugs with O-ring)
  • Requires special length 1/2" head bolts M-6065-BOSS or head studs M-6014-BOSS
  • Cast from diesel grade iron – far superior to any Ford OE block ever produced
  • Uses common OD cam bearings M-6261-J351
  • Unique cam plug M-6026-S351 included
  • M-6051-S331 or M-6051-CP331 head gasket recommended
  • Compatible with vehicles equipped with the original 302 and 351W block
  • Designed to use stock type timing cover, M-6059-D351 recommended
  • Retains clutch cross shaft pivot hole
  • Original style oil filter location
  • Original motor mount boss locations
  • Original bell housing pattern
  • Weight: approximately 175 lbs

Compatible Cylinder Heads

  • X306, X307, X2, C3, D3, Z304DA, Z2, GT40P

NOT Compatible With

  • Production 302/351W (GT40P is compatible)
  • M-6049-Y302, Y303, X302, X303, X304, X305
