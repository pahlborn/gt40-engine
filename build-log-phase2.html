Cam & Timing (Steuertrieb)
1. Cam Bearings (Cam-Lager) – check / replace if needed

Prerequisites (Voraussetzungen)

  • Phase 1: cam bearing type (R351/J351) identified
  • Phase 1: cam journal diameters measured
  • Calculate actual clearance: Bearing I.D. − Journal ø
Required Clearance0.001"–0.003" (0.025–0.076 mm)

Tools (only if replacing)

  • Cam bearing installation tool (Einpresswerkzeug)
  • Brass or plastic hammer

Practical Tips (Praxis-Tipps)

  • Only replace if type conflict or visible wear
  • Oil holes MUST align with block galleries after press-in!
  • Always install with oil – never press in dry
2. Install Camshaft (Nockenwelle einsetzen)

Tools (Werkzeuge)

  • Long bolt 5/16"-18 × 4" (7.94 mm × 102 mm) as guide handle (in cam nose thread)

Consumables (Betriebsmittel)

  • Assembly lube (COMP 159 or equivalent) on ALL lobes
  • Engine oil on all 5 journals

Practical Tips

  • Insert cam straight and slowly – lobes must NEVER touch bearing shells
  • The long bolt as handle gives control – without it the cam slides in uncontrolled
  • Tilt block slightly rearward (rear end lower) – gravity helps

Time Estimate (Zeitbedarf)

  • ~15 min.
3. Thrust Plate + Timing Set – install (montieren)

Procedure (Vorgehensweise)

  • Install thrust plate (retaining plate) with bolts finger-tight
  • Install crank sprocket on crankshaft keyway
  • Install cam sprocket – use “0”/STD keyway position
  • Route chain over both sprockets – timing marks dot-to-dot

Torque Values (Anzugswerte)

Thrust Plate Bolts9–12 ft-lbs (12–16 Nm)
Cam Bolt (ARP 254-1001)25–30 ft-lbs (34–41 Nm) w/ ARP lube
4. Cam Endplay (Axialspiel) – 0.001"–0.007" (0.025–0.178 mm)

Tools (Werkzeuge)

  • Dial indicator (Messuhr) with magnetic base
  • Screwdriver for prying (carefully!)

Target Values (Sollwerte)

Cam Endplay (Ford Spec)0.001"–0.007" (0.025–0.178 mm)
Service Limit0.009" (0.229 mm)

Procedure (Messverfahren)

  • Cam must be installed with thrust plate mounted
  • Place dial indicator axial on front cam end (or on cam sprocket face)
  • Push cam fully forward, zero indicator
  • Push cam fully rearward, read difference = endplay

Practical Tips

  • Too much play = thrust plate worn or wrong thickness
  • Too little play = cam may bind when engine is warm (thermal expansion)
5. Install Lifter on Test Cylinder #1 (Prüfzylinder)
6. Degree Camshaft (Nockenwelle degreen) – verify ICL

Tools (Werkzeuge)

  • Degree wheel ≥ 9" (229 mm) diameter
  • Pointer (Zeiger), mounted to block
  • Dial indicator with lifter adapter
  • Piston stop (steel or rubber)
  • Checking spring (light spring, replaces valve spring)

Target Values – COMP XE274HR

Intake Centerline (ICL)Per cam card (laut Cam Card)
Duration @.050" Int/Exh224° / 232°
Lobe Separation Angle (LSA)112°
Valve Lift Int/Exh0.555" / 0.565" (14.10 / 14.35 mm)

Procedure (6 Steps)

  • 1. Mount degree wheel on crank snout, pointer on block
  • 2. Find true TDC: install piston stop, rotate crank against stop (both directions), split the difference = TDC
  • 3. Place dial indicator on #1 intake lifter
  • 4. Slowly rotate crank, find max lift point
  • 5. Read degree wheel at .050" (1.27 mm) lifter rise on each side of max lift
  • 6. Midpoint = Intake Centerline (ICL)
EVERY camshaft must be degreed! Manufacturing tolerances can mean 2–4° deviation. This significantly changes engine character.

Photo Documentation (Fotodokumentation)

  • Degree wheel with pointer at TDC
  • Dial indicator reading at .050" opening and closing

Time Estimate

  • ~90 min. (incl. TDC finding)
7. Install All 16 Lifters (alle 16 Lifter einsetzen)

Practical Tips

  • Align link-bars parallel to cam, flat side facing valley
  • Note positions or label – reinstall in same position if removed!
  • Lifters must slide freely in their bores
Heads & Valvetrain Mock-up (Köpfe & Ventiltrieb)
8. Mock-up Gasket + Head – finger-tight only
Use Fel-Pro 1011-x as mock-up gasket! The M-6051-CP331 is a single-use copper gasket – stays in packaging until Phase 3. Kupfer-Kopfdichtung CP331 ist ein Einwegteil – niemals für Mock-up verwenden!

Practical Tips

  • Finger-tight with a few nuts only – no torque needed
  • Head must sit on dowel pins – must not shift
9. Install Guide Plates (Führungsplatten montieren)
10. Determine Pushrod Length (Pushrod-Länge ermitteln)

Tools (Werkzeuge)

  • CNC-TC6878 Checking Pushrod (adjustable)
  • Caliper (Messschieber) to read length

Procedure (9 Steps)

  • 1. Rotate cam to base circle (Grundkreis) – lifter in valley
  • 2. Insert checking pushrod at estimated length
  • 3. Install rocker, tighten adjusting nut to zero lash (Nullspiel)
  • 4. Color valve stem tip with felt-tip marker
  • 5. Cycle valve through full lift (rotate cam by hand)
  • 6. Read sweep pattern on valve stem:
    • Narrow band centered = correct
    • Band offset outward (exhaust) = pushrod too long
    • Band offset inward (center) = pushrod too short
    • Wide band = wrong length – valve guide suffers!
  • 7. Adjust checking pushrod and repeat steps 4–6
  • 8. Read final checking pushrod length
  • 9. Measure intake and exhaust SEPARATELY – lengths may differ!
Correct pushrod length depends on lifter, block deck, head, gasket, rocker, and valve. There is NO standard value – ALWAYS measure! AFR-Köpfe haben leicht nach innen gestellte Rockergeometrie – Pushrod-Länge unbedingt mit Checking Pushrod ermitteln, nicht schätzen.

Measurement Entry

Release Criteria (Freigabe)

  • Intake and exhaust lengths documented
  • Sweep check (next step) confirms the length

Time Estimate

  • ~60 min.
11. Rocker Sweep Check (Filzstift-Methode)

Procedure

  • 1. Color valve stem tip completely with felt-tip marker
  • 2. Cycle valve through full lift (rotate cam by hand)
  • 3. Read contact pattern on valve stem:
  • • Narrow band, centered = pushrod length correct
  • • Band offset outward (toward exhaust) = pushrod too long
  • • Band offset inward (toward center) = pushrod too short
  • • Wide band = wrong length – valve guide suffers!

Photo Documentation

  • Sweep pattern on valve stem (document both good and bad patterns)
12. Piston-to-Valve Clearance (P-V, Knetmasse)

Tools (Werkzeuge)

  • Modeling clay (Knetmasse), ~0.120" / 3 mm thick
  • Checking springs (light springs) – NOT the #8605 valve springs!
  • Razor blade / scalpel for cutting
  • Caliper (Messschieber)

Target Values (Sollwerte)

P-V Intake min.≥ 0.080" (2.03 mm)
P-V Exhaust min.≥ 0.100" (2.54 mm)

Procedure (7 Steps)

  • 1. Place clay ~0.120" (3 mm) thick on piston crown over valve pockets
  • 2. Install checking springs (NOT the real #8605 springs!)
  • 3. Place head with mock-up gasket, finger-tight
  • 4. Rotate crankshaft min. 2 full turns
  • 5. Remove head, carefully peel clay off piston
  • 6. Cut clay at thinnest point, measure with caliper
  • 7. Record intake and exhaust valve clearances separately
Insufficient P-V Clearance = valve hits piston! This destroys valves, pistons, and possibly connecting rods. When in doubt, have valve pockets machined deeper.

Practical Tips

  • If clearance too small: deepen valve pockets, use thicker gasket, or adjust cam timing
  • Always measure on the tightest cylinder (highest piston deck, smallest valve pocket)

Photo Documentation

  • Clay before measurement (mark thinnest point)
  • Caliper on clay cross-section
13. Quench Distance – Solder Wire Method (Quench-Abstand)

Tools (Werkzeuge)

  • Solder wire ~0.060"–0.090" (1.52–2.29 mm) diameter (lead-free)
  • Grease (to hold solder in place)
  • Micrometer or caliper (Messschieber)

Target Values (Sollwerte)

Quench Distance0.035"–0.045" (0.89–1.14 mm)

Procedure

  • 1. Cut 2–3 short pieces of solder wire (~1" / 25 mm long)
  • 2. Use grease to stick solder on quench area of piston crown (flat area, NOT in valve pocket)
  • 3. Install head with mock-up gasket, finger-tight
  • 4. Rotate crankshaft slowly over TDC – wire gets crushed between piston and head
  • 5. Remove head. Measure crushed wire thickness with micrometer
  • 6. Repeat for all 8 cylinders

Practical Tips

  • Alternative method: Measure piston-to-deck with dial indicator (without head) and add compressed gasket thickness. Less accurate but non-destructive.
  • Quench too large = less detonation resistance, less efficient combustion
  • Quench too small = piston may contact head (thermal expansion at operating temp)
