Cam & Timing (Steuertrieb)
1. Cam Bearings (Cam-Lager) – check / replace if needed

Prerequisites (Voraussetzungen)

  • Phase 1: cam bearing type (R351/J351) identified
  • Phase 1: cam journal diameters measured
  • Calculate actual clearance: Bearing I.D. − Journal ø
Required Clearance0.001"–0.003" (0.025–0.076 mm)

Tools (only if replacing)

  • Cam bearing installation tool (Einpresswerkzeug)
  • Brass or plastic hammer

Practical Tips (Praxis-Tipps)

  • Only replace if type conflict or visible wear
  • Oil holes MUST align with block galleries after press-in!
  • Always install with oil – never press in dry
2. Install Camshaft (Nockenwelle einsetzen)

Tools (Werkzeuge)

  • Long bolt 5/16"-18 × 4" (7.94 mm × 102 mm) as guide handle (in cam nose thread)

Consumables (Betriebsmittel)

  • Assembly lube (COMP 159 or equivalent) on ALL lobes
  • Engine oil on all 5 journals

Practical Tips

  • Insert cam straight and slowly – lobes must NEVER touch bearing shells
  • The long bolt as handle gives control – without it the cam slides in uncontrolled
  • Tilt block slightly rearward (rear end lower) – gravity helps

Time Estimate (Zeitbedarf)

  • ~15 min.
3. Thrust Plate + Timing Set – install (montieren)

Procedure (Vorgehensweise)

  • Install thrust plate (retaining plate) with bolts finger-tight
  • Install crank sprocket on crankshaft keyway
  • Install cam sprocket – use “0”/STD keyway position
  • Route chain over both sprockets – timing marks dot-to-dot

Torque Values (Anzugswerte)

Thrust Plate Bolts9–12 ft-lbs (12–16 Nm)
Cam Bolt (ARP 254-1001)25–30 ft-lbs (34–41 Nm) w/ ARP lube
4. Cam Endplay (Axialspiel) – 0.001"–0.007" (0.025–0.178 mm)

Tools (Werkzeuge)

  • Dial indicator (Messuhr) with magnetic base
  • Screwdriver for prying (carefully!)

Target Values (Sollwerte)

Cam Endplay (Ford Spec)0.001"–0.007" (0.025–0.178 mm)
Service Limit0.009" (0.229 mm)

Procedure (Messverfahren)

  • Cam must be installed with thrust plate mounted
  • Place dial indicator axial on front cam end (or on cam sprocket face)
  • Push cam fully forward, zero indicator
  • Push cam fully rearward, read difference = endplay

Practical Tips

  • Too much play = thrust plate worn or wrong thickness
  • Too little play = cam may bind when engine is warm (thermal expansion)
5. Install Lifter on Test Cylinder #1 (Prüfzylinder)

Preparation (Vorbereitung)

  • Camshaft installed and timing set in place
  • One COMP hydraulic roller lifter (from set of 16) ready
  • Rotate crank so #1 intake lobe is on base circle (Grundkreis)
  • Identify #1 intake lifter bore (passenger side, front)

Tools (Werkzeuge)

  • Assembly lube (COMP #106 or equivalent)
  • Clean lint-free cloth
  • Flashlight for bore inspection
  • Long screwdriver or pushrod to check lifter rotation

Procedure (Vorgehensweise)

  1. Clean bore: Wipe #1 intake lifter bore with clean cloth – remove any debris or preservative oil (Bohrung reinigen)
  2. Lubricate: Apply assembly lube to lifter body and inside of lifter bore (Montagepaste auf Lifter und Bohrung)
  3. Align roller: Orient lifter so roller wheel is aligned parallel with camshaft lobe – roller must track straight on lobe (Rolle muss parallel zur Nocke ausgerichtet sein)
  4. Insert lifter: Slide lifter into bore – it should drop in freely under its own weight (Lifter muss frei gleiten)
  5. Check rotation: Lifter must NOT rotate in bore – link bar slot prevents rotation on hydraulic roller lifters (Lifter darf sich nicht in der Bohrung drehen)
  6. Verify free movement: Push lifter down and release – it should spring back up freely, no binding (frei auf und ab gleiten)

Tips (Praxis-Tipps)

  • This is a test lifter only – used for degreeing cam and checking pushrod length
  • If lifter binds in bore: check for burrs, debris, or wrong lifter diameter
  • Hydraulic roller lifters use link bars to prevent rotation – link bar not needed for single test lifter, but verify roller alignment manually
  • Lifter-to-bore clearance: 0.0010"–0.0025" (0.025–0.064 mm) typical
6. Degree Camshaft (Nockenwelle degreen) – verify ICL

Tools (Werkzeuge)

  • Degree wheel ≥ 9" (229 mm) diameter
  • Pointer (Zeiger), mounted to block
  • Dial indicator with lifter adapter
  • Piston stop (steel or rubber)
  • Checking spring (light spring, replaces valve spring)

Target Values – COMP XE274HR

Intake Centerline (ICL)Per cam card (laut Cam Card)
Duration @.050" Int/Exh224° / 232°
Lobe Separation Angle (LSA)112°
Valve Lift Int/Exh0.555" / 0.565" (14.10 / 14.35 mm)

Procedure (6 Steps)

  • 1. Mount degree wheel on crank snout, pointer on block
  • 2. Find true TDC: install piston stop, rotate crank against stop (both directions), split the difference = TDC
  • 3. Place dial indicator on #1 intake lifter
  • 4. Slowly rotate crank, find max lift point
  • 5. Read degree wheel at .050" (1.27 mm) lifter rise on each side of max lift
  • 6. Midpoint = Intake Centerline (ICL)
EVERY camshaft must be degreed! Manufacturing tolerances can mean 2–4° deviation. This significantly changes engine character.

Photo Documentation (Fotodokumentation)

  • Degree wheel with pointer at TDC
  • Dial indicator reading at .050" opening and closing

Time Estimate

  • ~90 min. (incl. TDC finding)
7. Install All 16 Lifters (alle 16 Lifter einsetzen)

Practical Tips

  • Align link-bars parallel to cam, flat side facing valley
  • Note positions or label – reinstall in same position if removed!
  • Lifters must slide freely in their bores
Heads & Valvetrain Mock-up (Köpfe & Ventiltrieb)
8. Mock-up Gasket + Head – finger-tight only
Use Fel-Pro 1011-x as mock-up gasket! The M-6051-CP331 is a single-use copper gasket – stays in packaging until Phase 3. Kupfer-Kopfdichtung CP331 ist ein Einwegteil – niemals für Mock-up verwenden!

Practical Tips

  • Finger-tight with a few nuts only – no torque needed
  • Head must sit on dowel pins – must not shift
9. Install Guide Plates (Führungsplatten montieren)

Preparation (Vorbereitung)

  • COMP Cams flat-style guide plates (for AFR 1399 heads)
  • Cylinder head(s) mock-installed with gasket and finger-tight nuts
  • Lifters installed in bores
  • Checking pushrod or final pushrods available

Tools (Werkzeuge)

  • 3/8" socket or wrench for guide plate bolts
  • Rocker arm studs installed in head
  • Straightedge or pushrod for alignment check
  • Flashlight for visual inspection

Procedure (Vorgehensweise)

  1. Identify orientation: Flat side of guide plate faces UP for AFR heads – check COMP instructions for specific head (flache Seite nach oben für AFR-Köpfe)
  2. Position on studs: Slide guide plate over rocker studs between each pair of intake/exhaust pushrods (Führungsplatte über Kipphebel-Stehbolzen schieben)
  3. Insert pushrod: Drop checking pushrod through guide plate slot into lifter cup (Pushrod durch Schlitz in Lifter einsetzen)
  4. Check alignment: Pushrod must be centered in guide plate slot – no contact with slot edges at rest (Pushrod muss mittig im Schlitz laufen)
  5. Rotate cam through full cycle: Verify pushrod does not bind or deflect against guide plate edges at any point in the lift cycle (kein Verklemmen über den gesamten Hub)
  6. Verify all positions: Repeat for all 8 guide plates (16 pushrod positions) (für alle 8 Platten wiederholen)

Tips (Praxis-Tipps)

  • Guide plates prevent pushrod side-loading on valve tips – critical for valve guide longevity (verhindert seitliche Belastung der Ventilführungen)
  • AFR 1399 heads use pedestal-mount rockers – verify guide plate is compatible with stud spacing
  • If pushrod contacts slot edge: wrong guide plate type, incorrect pushrod length, or misaligned rocker stud
  • Do NOT fully torque guide plates during mock-up – finger-tight only, final torque in Phase 3
  • Some builders lightly scuff pushrod with marker to check for guide plate contact marks
10. Determine Pushrod Length (Pushrod-Länge ermitteln)

Tools (Werkzeuge)

  • CNC-TC6878 Checking Pushrod (adjustable)
  • Caliper (Messschieber) to read length

Procedure (9 Steps)

  • 1. Rotate cam to base circle (Grundkreis) – lifter in valley
  • 2. Insert checking pushrod at estimated length
  • 3. Install rocker, tighten adjusting nut to zero lash (Nullspiel)
  • 4. Color valve stem tip with felt-tip marker
  • 5. Cycle valve through full lift (rotate cam by hand)
  • 6. Read sweep pattern on valve stem:
    • Narrow band centered = correct
    • Band offset outward (exhaust) = pushrod too long
    • Band offset inward (center) = pushrod too short
    • Wide band = wrong length – valve guide suffers!
  • 7. Adjust checking pushrod and repeat steps 4–6
  • 8. Read final checking pushrod length
  • 9. Measure intake and exhaust SEPARATELY – lengths may differ!
Correct pushrod length depends on lifter, block deck, head, gasket, rocker, and valve. There is NO standard value – ALWAYS measure! AFR-Köpfe haben leicht nach innen gestellte Rockergeometrie – Pushrod-Länge unbedingt mit Checking Pushrod ermitteln, nicht schätzen.

Measurement Entry

Release Criteria (Freigabe)

  • Intake and exhaust lengths documented
  • Sweep check (next step) confirms the length

Time Estimate

  • ~60 min.
11. Rocker Sweep Check (Filzstift-Methode)

Procedure

  • 1. Color valve stem tip completely with felt-tip marker
  • 2. Cycle valve through full lift (rotate cam by hand)
  • 3. Read contact pattern on valve stem:
  • • Narrow band, centered = pushrod length correct
  • • Band offset outward (toward exhaust) = pushrod too long
  • • Band offset inward (toward center) = pushrod too short
  • • Wide band = wrong length – valve guide suffers!

Photo Documentation

  • Sweep pattern on valve stem (document both good and bad patterns)
12. Piston-to-Valve Clearance (P-V, Knetmasse)

Tools (Werkzeuge)

  • Modeling clay (Knetmasse), ~0.120" / 3 mm thick
  • Checking springs (light springs) – NOT the #8605 valve springs!
  • Razor blade / scalpel for cutting
  • Caliper (Messschieber)

Target Values (Sollwerte)

P-V Intake min.≥ 0.080" (2.03 mm)
P-V Exhaust min.≥ 0.100" (2.54 mm)

Procedure (7 Steps)

  • 1. Place clay ~0.120" (3 mm) thick on piston crown over valve pockets
  • 2. Install checking springs (NOT the real #8605 springs!)
  • 3. Place head with mock-up gasket, finger-tight
  • 4. Rotate crankshaft min. 2 full turns
  • 5. Remove head, carefully peel clay off piston
  • 6. Cut clay at thinnest point, measure with caliper
  • 7. Record intake and exhaust valve clearances separately
Insufficient P-V Clearance = valve hits piston! This destroys valves, pistons, and possibly connecting rods. When in doubt, have valve pockets machined deeper.

Practical Tips

  • If clearance too small: deepen valve pockets, use thicker gasket, or adjust cam timing
  • Always measure on the tightest cylinder (highest piston deck, smallest valve pocket)

Photo Documentation

  • Clay before measurement (mark thinnest point)
  • Caliper on clay cross-section
13. Quench Distance – Solder Wire Method (Quench-Abstand)

Tools (Werkzeuge)

  • Solder wire ~0.060"–0.090" (1.52–2.29 mm) diameter (lead-free)
  • Grease (to hold solder in place)
  • Micrometer or caliper (Messschieber)

Target Values (Sollwerte)

Quench Distance0.035"–0.045" (0.89–1.14 mm)

Procedure

  • 1. Cut 2–3 short pieces of solder wire (~1" / 25 mm long)
  • 2. Use grease to stick solder on quench area of piston crown (flat area, NOT in valve pocket)
  • 3. Install head with mock-up gasket, finger-tight
  • 4. Rotate crankshaft slowly over TDC – wire gets crushed between piston and head
  • 5. Remove head. Measure crushed wire thickness with micrometer
  • 6. Repeat for all 8 cylinders

Practical Tips

  • Alternative method: Measure piston-to-deck with dial indicator (without head) and add compressed gasket thickness. Less accurate but non-destructive.
  • Quench too large = less detonation resistance, less efficient combustion
  • Quench too small = piston may contact head (thermal expansion at operating temp)

Per-Cylinder Measurements (8 Zylinder)

14. Retainer-to-Seal Clearance at max lift

Target Value (Sollwert)

Min. Retainer–Seal gap≥ 0.060" (1.52 mm)

Practical Tips

  • Measure at max lift: retainer must not contact valve stem seal
  • Contact = seal destroyed = oil consumption
Dry Fit Accessories (Trockenpassung Anbauteile)
15. Intake Manifold (Ansaugbrücke) – dry fit

Inspection Points (Prüfpunkte)

  • Port alignment: intake port must align with head port (witness marks)
  • Max. mismatch: < 1/16" (1.59 mm) – otherwise flow loss
  • Check 4 corner fitment (block-to-pan rail area)
16. Oil Pump (Ölpumpe) + Drive Shaft – dry fit

Preparation (Vorbereitung)

  • Melling M-68 oil pump ready (or Ford M-6600-D2)
  • Oil pump intermediate drive shaft (ARP or OEM)
  • Block rear main area accessible

Tools (Werkzeuge)

  • 3/4" combination wrench (19 mm)
  • Long screwdriver for alignment
  • Inspection mirror

Procedure (Vorgehensweise)

  • 1. Shaft alignment: Insert intermediate shaft into block – hex end must engage camshaft gear (Sechskant muss in Nockenwellen-Antriebszahnrad greifen)
  • 2. Drive shaft length: Shaft must extend below block far enough to engage pump rotor – verify ~0.5" (12.7 mm) protrusion below pump mounting pad
  • 3. Pump mounting: Set pump on rear main cap mounting pad – bolt finger-tight only
  • 4. Rotation check: Turn shaft by hand (screwdriver in hex) – must rotate freely without binding
  • 5. Pickup alignment: Verify pickup tube direction points toward pan sump area

Tips (Praxis-Tipps)

  • If shaft won’t engage cam gear: rotate crank slightly to align gears
  • Shaft must NOT bottom out against cam gear – verify 0.010"–0.030" (0.25–0.76 mm) clearance
  • Mark orientation of pump body for Phase 3 reinstall
17. Timing Cover – dry fit

Preparation (Vorbereitung)

  • Timing chain and sprockets installed from degreeing step
  • Ford timing cover + gasket ready
  • Front crank seal ready (do NOT install yet – dry fit only)

Tools (Werkzeuge)

  • 3/8" socket set (Nusskasten)
  • Straightedge for gasket alignment check
  • Feeler gauge 0.010" (0.25 mm)

Procedure (Vorgehensweise)

  • 1. Gasket alignment: Place gasket dry on block – all bolt holes and water passages must align perfectly (alle Bohrungen und Wasserdurchlässe müssen fluchten)
  • 2. Cover fitment: Slide cover over crank snout – must clear timing chain sprocket
  • 3. Seal bore check: Verify front seal bore is concentric with crank snout – no offset that would damage seal
  • 4. Pan rail alignment: Cover bottom edge must be flush with block oil pan rail – check with straightedge (Unterkante muss bündig mit Block-Wannenschiene sein)
  • 5. Balancer clearance: With cover loosely in place, verify harmonic balancer can slide through seal bore without interference

Tips (Praxis-Tipps)

  • Cover goes on BEFORE oil pan – pan seals against cover bottom edge
  • Aftermarket covers may need trimming at pan rail – check now, not during final assembly
  • Note bolt lengths – Ford covers often use 2–3 different lengths
18. Oil Pan (Ölwanne) – clearance, pickup distance

Preparation (Vorbereitung)

  • Canton Road Race pan #15-644 (or selected pan) ready
  • Oil pump + pickup installed from previous step
  • Pan gaskets (side rails + end seals) ready for dry check

Tools (Werkzeuge)

  • Ruler or caliper for pickup clearance measurement
  • Flashlight for internal inspection
  • 3/8" socket set

Procedure (Vorgehensweise)

  • 1. Gasket alignment: Lay side gaskets + end seals dry on block – verify all bolt holes align with pan
  • 2. Pan clearance: Set pan in place – check that pickup tube and pump body clear pan interior (Saugrüssel und Pumpe dürfen Wanne innen nicht berühren)
  • 3. Pickup-to-pan bottom: Measure from bottom of pickup screen to inside bottom of pan – target 1/4"–3/8" (6.4–9.5 mm)
  • 4. Dipstick tube: Verify dipstick tube boss aligns with block or pan provision
  • 5. Windage tray: If Canton pan includes windage tray, check clearance to crank counterweights – min. 1/4" (6.4 mm)
  • 6. Drain plug: Verify drain plug is accessible and in correct position for chassis

Tips (Praxis-Tipps)

  • Canton Road Race pans are deeper in rear – verify chassis ground clearance for mid-engine applications
  • Mark pickup-to-pan measurement for Phase 3 verification
  • Check for interference with steering rack, crossmember, or frame rails if applicable
19. Pickup-to-Pan Bottom: 1/4"–3/8" (6.4–9.5 mm)

Tools (Werkzeuge)

  • Ruler, caliper, or bent wire gauge
  • Modeling clay (Knetmasse) – alternative measurement method

Target Values (Sollwerte)

Pickup-to-Pan Bottom1/4"–3/8" (6.4–9.5 mm)
Ideal5/16" (8 mm)

Procedure (Vorgehensweise)

  • Method A (Direct): With pan loosely in place, measure from pickup screen bottom to pan floor with ruler through drain hole or bolt hole
  • Method B (Clay): Place modeling clay on pan floor, set pan on block, remove and measure compressed clay thickness
  • Method C (Wire): Bend wire to known length, insert through drain hole to touch pickup – calculate distance
CRITICAL for oil starvation prevention! Too close (<1/4") = cavitation & oil aeration under load. Too far (>3/8") = air ingestion during hard cornering/acceleration when oil level drops. (Zu nah = Kavitation. Zu weit = Luft ansaugen bei Kurvenfahrt.)

Tips (Praxis-Tipps)

  • If clearance is wrong, bend pickup tube carefully (small adjustments only!) or use a different pickup
  • This is the MOST critical oil system dimension – recheck in Phase 3 before final pan installation
  • Mid-engine/track cars: err toward closer (1/4") to prevent uncovering under G-loads
20. Valve Covers (Ventildeckel) – rocker clearance

Preparation (Vorbereitung)

  • Rockers + polylocks installed on at least test cylinder
  • Valve covers + gaskets ready

Tools (Werkzeuge)

  • Modeling clay (Knetmasse) ~3/16" (5 mm) thick
  • Caliper for measuring compressed clay

Procedure (Vorgehensweise)

  • 1. Rocker clearance: Place modeling clay on highest points of rocker arms (adjusting nut / polylock area)
  • 2. Set valve cover on head with gasket, press down evenly
  • 3. Remove cover, measure clay thickness – minimum clearance: 1/8" (3.2 mm) to any rocker component
  • 4. Gasket seal: Check gasket rail seating – gasket must sit flat with no gaps
  • 5. PCV/breather: Verify PCV valve and breather grommet positions match planned routing
  • 6. Bolt holes: Verify all mounting holes align – aftermarket covers may differ from OEM pattern

Tips (Praxis-Tipps)

  • COMP 1632-16 rockers with polylocks are taller than stock – standard covers often don’t clear!
  • If interference: use tall/fabricated covers, or spacers (Abstandshalter) under cover gasket rail
  • Note clearance issues now – order correct covers before Phase 3
21. Distributor (Verteiler) – intake clearance

Preparation (Vorbereitung)

  • MSD distributor ready (Pro-Billet or Ready-to-Run)
  • Intake manifold dry-fitted or in place from step 15
  • Crank at TDC #1 compression stroke

Tools (Werkzeuge)

  • 1/2" open-end wrench for hold-down clamp
  • Flashlight for gear mesh inspection

Procedure (Vorgehensweise)

  • 1. Gear mesh: Drop distributor into block – drive gear must mesh with cam gear. Slight rotation during insertion is normal (helical gear / Schrägverzahnung)
  • 2. Rotor alignment: At TDC #1 compression, rotor tip should point toward #1 spark plug wire tower on cap
  • 3. Intake clearance: With intake manifold in place, check clearance between distributor body/cap and intake manifold runners – minimum 1/4" (6.4 mm)
  • 4. Hold-down clamp: Verify clamp fits in block groove and can secure distributor
  • 5. Vacuum advance: Check vacuum canister clearance to firewall/bulkhead and accessories

Tips (Praxis-Tipps)

  • MSD distributors are slightly larger than stock Ford – verify clearance to intake plenum, A/C compressor, etc.
  • Note the number of teeth offset during insertion (gear helix causes ~1 tooth rotation)
  • If distributor won’t seat fully: oil pump shaft may not be aligned – wiggle or rotate slightly
  • Mark distributor body position relative to block for Phase 3 reference
Mock-up Conclusion (Abschluss)
22. Order Final Pushrods (finale Pushrods bestellen)

Prerequisites (Voraussetzungen)

  • Pushrod length determined in step 10 (checking pushrod)
  • Sweep check confirmed in step 11
  • Both intake and exhaust lengths documented

Order Specifications (Bestelldaten)

Diameter (Durchmesser)5/16" (7.94 mm) or 3/8" (9.53 mm)
Wall Thickness (Wandstärke)0.080" (2.03 mm) for performance
Material4130 Chromoly
Tip Style5/16" ball + 5/16" cup (std SBF)

Tips (Praxis-Tipps)

  • COMP Cams, Smith Brothers, or Trend for custom lengths – specify to nearest 0.025" increment
  • Order 1–2 extras per length in case of damage during assembly
  • Heat-treated chromoly is stronger than standard; recommended for hydraulic roller with high spring pressures
  • Typical lead time: 1–3 weeks for custom lengths (Lieferzeit: 1–3 Wochen)
  • Verify 5/16" diameter clears COMP guideplate slots – if using 3/8", need matching guideplates
23. Complete Teardown – label all parts (zerlegen & beschriften)

Tools (Werkzeuge)

  • Zip-lock bags (verschiedene Größen)
  • Permanent marker + masking tape for labeling
  • Parts organizer trays
  • Clean lint-free cloths (fusselfreie Tücher)
  • Assembly lube (for coating bare surfaces)

Disassembly Order (Zerlegungsreihenfolge)

  • 1. Remove distributor (Verteiler abnehmen)
  • 2. Remove valve covers (Ventildeckel)
  • 3. Remove rockers, polylocks, pushrods – bag per cylinder! (pro Zylinder einpacken!)
  • 4. Remove intake manifold (Ansaugbrücke)
  • 5. Remove heads (Köpfe) – bag ARP nuts + washers separately per side
  • 6. Remove lifters – maintain numbering! (Lifter – Nummerierung beibehalten!)
  • 7. Remove oil pan + pickup (Wanne + Saugrohr)
  • 8. Remove oil pump (Pumpe)
  • 9. Remove timing cover, chain, sprockets (Steuerkettendeckel, Kette, Zahnräder)
  • 10. Remove camshaft (Nockenwelle)

Tips (Praxis-Tipps)

  • Label everything! Lifters, pushrods, and rockers must return to their exact positions (Alles beschriften! Lifter, Pushrods und Kipphebel müssen exakt an ihren Platz zurück)
  • Coat all bare metal surfaces (crank journals, cam lobes) with oil or assembly lube to prevent surface rust
  • Bag hardware per location: "LH Head Nuts", "Timing Cover Bolts", etc.
  • Remove and discard mock-up gasket (Fel-Pro 1011) – NOT reusable (Probedichtung NICHT wiederverwendbar)
  • Store parts clean and dry in a dust-free area until Phase 3

Time Estimate (Zeitbedarf)

  • ~2–3 hours including labeling and packaging (inkl. Beschriften und Verpacken)
